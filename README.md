# Saffron & Stone — Restaurant Landing Page

Saffron & Stone is a modern restaurant website concept designed to create an elegant online presence for a restaurant. It combines a warm visual style with clear content sections to introduce the restaurant, highlight its menu, and provide essential visitor information.

## Features

- Modern restaurant-focused design
- Responsive layout for desktop, tablet, and mobile
- Restaurant introduction and story
- Featured menu items
- Restaurant values and dining experience
- Navigation with a mobile-friendly menu
- Contact and location information

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Getting Started

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

You can also use the Live Server extension in Visual Studio Code for local development.
